In this repository I'm collecting some projects I made for time series analysis.

In "US_GDP_disagg_R" folder you find the R code to import quarterly gdp data (from Fred API) and then transform them in monthly data.

In "Making dataset" folder you find my python code to import some economic and financial data from Fred API and yahoo finance API. I transform them in log return data, stationary, suitable for econometric and statistical analysis
